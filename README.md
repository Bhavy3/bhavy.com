# Bhavy Gajjar | Data Scientist & AI/ML Developer

Personal portfolio and 3D interactive showcase for **Bhavy Gajjar** — Data Scientist at Vibrant Technology.

Features:
- Built with Vue 3, Three.js 3D particle systems, and kinetic typography
- Live interactive local assistant for answering questions about projects and background
- 3D Particle Story mode (`?v=story`) illustrating the journey from early curiosity to Data Science and FRIDAY
- Zero external audio dependencies with procedural ambient sound synthesis via Web Audio API
- Optimized Web Vitals with inlined critical paint shells

## Requirements

- Node.js 18 or newer

## Run Locally

```bash
npm start
```

Open [http://localhost:4173/](http://localhost:4173/).

## Entry Points

- `/` : Interactive experience gate (Site vs 3D Story)
- `/?v=site` : Standard scrollable portfolio
- `/?v=story` : 3D spatial particle story
